# Pogoda — Weather Trading Bot for Polymarket

Торговый бот для рынков погоды на Polymarket. Использует консенсус трёх метеомоделей (ECMWF, GFS, ICON) для принятия торговых решений с низким уровнем риска.

## Стратегия

1. **Сбор данных**: Прогнозы с трёх моделей (ECMWF, GFS, ICON) через Open-Meteo API
2. **Консенсус**: Все три модели должны сходиться на одной температуре (±1°C)
3. **Ставки**: Покупка центрального бина + соседних (±1°C) одинаковым количеством долей
4. **Лотерейные бины**: Опционально — бины ±2°C (стоят ~1¢, потенциал 100x)
5. **Только лимитные ордера** — никаких маркет-ордеров

### Чек-лист входа в сделку

- ✅ Известна метеостанция (аэропорт) из правил рынка
- ✅ Консенсус трёх моделей (или подтверждение резервных источников)
- ✅ Суммарная стоимость всех бинов < 96¢
- ✅ Стабильная погода (прогноз ≈ факт текущего дня)
- ✅ Ожидаемая прибыль ≥ 10%

## Установка

```bash
pip install -e .
```

## Настройка

```bash
cp .env.example .env
# Заполните .env своими ключами Polymarket
```

### Переменные окружения

| Переменная | Описание |
|---|---|
| `POLYMARKET_API_KEY` | API ключ Polymarket |
| `POLYMARKET_API_SECRET` | API секрет |
| `POLYMARKET_API_PASSPHRASE` | Пароль API |
| `PRIVATE_KEY` | Приватный ключ кошелька (Polygon) |
| `SHARES_PER_BIN` | Кол-во долей на бин (по умолч. 10) |
| `MIN_PROFIT_PERCENT` | Мин. ожидаемая прибыль (по умолч. 10%) |
| `MAX_TOTAL_COST_CENTS` | Макс. стоимость всех бинов (по умолч. 96¢) |
| `ENABLE_LOTTERY_BINS` | Включить лотерейные бины ±2°C |

## Использование

### Проверить прогноз погоды
```bash
pogoda weather tokyo
pogoda weather london --date 2025-03-28
```

### Посмотреть активные рынки
```bash
pogoda markets
pogoda markets --city Tokyo
```

### Сканирование (dry-run)
```bash
pogoda scan                          # Все города
pogoda scan -c tokyo london          # Конкретные города
pogoda scan -c tokyo --date 2025-03-28
```

### Реальная торговля
```bash
pogoda scan --live                   # ⚠️ Реальные ордера!
pogoda scan -c tokyo --live
```

### Список поддерживаемых городов
```bash
pogoda cities
```

## Архитектура

```
pogoda/
├── config.py      # Настройки, координаты городов
├── weather.py     # Сбор данных: ECMWF, GFS, ICON + резервные источники
├── consensus.py   # Движок консенсуса моделей
├── polymarket.py  # Клиент Polymarket API (поиск рынков, бины)
├── strategy.py    # Стратегия ставок, чек-лист, генерация ордеров
├── trader.py      # Исполнение ордеров через CLOB API
├── bot.py         # Оркестратор — связывает все модули
└── cli.py         # CLI интерфейс
```

## Риск-менеджмент

- Максимальная позиция ограничена (`MAX_POSITION_SIZE_USD`)
- Суммарная стоимость бинов не должна превышать 96¢ (иначе гарантированный убыток)
- Проверка стабильности погоды перед входом
- Минимальная ожидаемая прибыль 10%
- Только лимитные ордера для контроля спреда
